Projects

My work focuses on building microwave photonic systems that improve oscillator purity, generate microwave frequency combs, and enable reconfigurable RF signal processing, while also exploring integrated photonic devices and optical communication systems.

Research Project
Direction 01 ASE-driven OEO

Light: Science & Applications, accepted 2026

Breaking the phase noise-mode purity trade-off in long-loop OEOs

This project introduces an ASE-driven OEO architecture based on cascaded zero-dispersion recirculating loops. The central achievement is breaking a long-lasting OEO trade-off: phase noise and mode purity, commonly difficult to improve simultaneously in long-loop OEOs, can be improved together.

Achievement
Simultaneous improvement of phase noise and sidemode suppression ratio.
Scheme
ASE-driven OEO with cascaded zero-dispersion recirculating loops.
Performance
Improved mode purity and phase-noise performance in a long-loop OEO architecture.

Laser & Photonics Reviews, in print 2026

Ultra-high-order harmonic mode-locked optoelectronic oscillator

This project demonstrates ultra-high-order harmonic mode-locking in an OEO and generates a microwave frequency comb. The work pushes the harmonic mode-locking order to the 956th order, the highest reported for a mode-locked OEO.

Achievement
956th-order harmonic mode-locking in a mode-locked OEO.
Scheme
Harmonic mode-locked recirculating-loop OEO architecture.
Performance
Microwave frequency comb generation with 92 MHz spacing.
Direction 02 Microwave Photonic Signal Processing

Journal of Lightwave Technology, 2025

Microwave photonic signal processor based on a quantum-dash mode-locked laser

This project uses a quantum-dash mode-locked laser as a multi-wavelength optical source for microwave photonic signal processing, including Hilbert-transform functionality.

Achievement
Versatile microwave photonic signal processing using a QD-MLL platform.
Scheme
Comb-line-based microwave photonic processor with programmable spectral control.
Performance
Experimental Hilbert-transform response enabled by the QD-MLL-based processor.

IEEE Transactions on Microwave Theory and Techniques, 2025

Independently tunable narrowband microwave photonic filter

This project demonstrates a highly reconfigurable narrowband microwave photonic filter based on a chirp-like sliced ASE source. The filter supports multiple passbands whose center frequencies can be tuned independently.

Achievement
Multi-passband microwave photonic filtering with independently tunable center frequencies.
Scheme
Chirp-like sliced ASE source mapped into a reconfigurable microwave photonic filter response.
Performance
Ultra-narrow passbands with bandwidths below 50 MHz.
Industry Collaboration Projects

Quasi-coherent optical communication using quantum-dash mode-locked lasers

A collaborative project on optical communication systems using quantum-dash optical frequency comb sources and quasi-coherent detection concepts. The project connects microwave photonics, optical frequency combs, and high-capacity communication link evaluation.

On-chip MMI design for silicon photonic circuits

An integrated photonics project focused on multimode-interference devices on a silicon-on-insulator platform, including compact passive components relevant to photonic integrated circuit design and characterization.
