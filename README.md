## GitHub Pages

This folder can be published directly as a static GitHub Pages site. Use the repository root as the Pages source and keep `index.html` at the top level.

## Files

- `index.html`: page structure and English academic content
- `styles.css`: responsive visual design
- `assets/zhuoran-wang-poster.jpg`: optimized hero photo
- `assets/zhuoran-wang-portrait.jpg`: cropped contact portrait
- `assets/Zhuoran_Wang_CV.pdf`: downloadable CV
